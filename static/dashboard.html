Setup Guide & Environment Settings

Learn how to redirect the Claude Code CLI tool through this local proxy gateway on Linux, macOS, or Windows.

Linux Setup Guide

Run this inside your terminal session (Bash/Zsh) or add it to ~/.bashrc / ~/.zshrc:

# Temporary terminal session
export ANTHROPIC_BASE_URL="http://127.0.0.1:8090"
export ANTHROPIC_AUTH_TOKEN="freecc"
claude

# Permanent setup (Bash/Zsh)
echo 'export ANTHROPIC_BASE_URL="http://127.0.0.1:8090"' >> ~/.bashrc
echo 'export ANTHROPIC_AUTH_TOKEN="freecc"' >> ~/.bashrc
source ~/.bashrc

Fish Shell Users:

set -ux ANTHROPIC_BASE_URL "http://127.0.0.1:8090"
set -ux ANTHROPIC_AUTH_TOKEN "freecc"
claude

macOS Setup Guide

macOS uses Zsh by default. Execute the following in Terminal or add to ~/.zshrc:

# Terminal export
export ANTHROPIC_BASE_URL="http://127.0.0.1:8090"
export ANTHROPIC_AUTH_TOKEN="freecc"
claude

# Permanent setup (Zsh)
echo 'export ANTHROPIC_BASE_URL="http://127.0.0.1:8090"' >> ~/.zshrc
echo 'export ANTHROPIC_AUTH_TOKEN="freecc"' >> ~/.zshrc
source ~/.zshrc

Fish Shell Users (macOS Homebrew):

set -ux ANTHROPIC_BASE_URL "http://127.0.0.1:8090"
set -ux ANTHROPIC_AUTH_TOKEN "freecc"
claude

Windows Setup Guide

PowerShell:

# Current PowerShell Session
$env:ANTHROPIC_BASE_URL="http://127.0.0.1:8090"
$env:ANTHROPIC_AUTH_TOKEN="freecc"
claude

# Permanent Environment Variables (PowerShell)
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_BASE_URL', 'http://127.0.0.1:8090', 'User')
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'freecc', 'User')

Command Prompt (CMD):

:: Current CMD Session
set ANTHROPIC_BASE_URL=http://127.0.0.1:8090
set ANTHROPIC_AUTH_TOKEN=freecc
claude

:: Permanent Environment Variables (CMD)
setx ANTHROPIC_BASE_URL "http://127.0.0.1:8090"
setx ANTHROPIC_AUTH_TOKEN "freecc"
