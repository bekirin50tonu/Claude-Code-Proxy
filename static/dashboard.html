Setup Guide & Environment Settings

Learn how to redirect the Claude Code CLI tool through this local proxy gateway.

1. Concept

By default, Claude Code connects directly to Anthropic's cloud endpoints. We redirect its traffic locally using the ANTHROPIC_BASE_URL environment variable. Since Claude Code requires an authentication token to initialize, we provide a dummy token freecc (or your custom Gateway Token) via ANTHROPIC_AUTH_TOKEN.

2. Bash / Zsh Shell Integration

Run this inside your terminal session to connect directly, or add it to your ~/.bashrc or ~/.zshrc file:

export ANTHROPIC_BASE_URL="http://127.0.0.1:8090"
export ANTHROPIC_AUTH_TOKEN="freecc"
claude

3. Fish Shell Integration

For Fish shell users, you can define a custom function (e.g., fcc-claude) in your fish configuration (~/.config/fish/functions/fcc-claude.fish):

function fcc-claude
    env ANTHROPIC_BASE_URL="http://127.0.0.1:8090" ANTHROPIC_AUTH_TOKEN="freecc" claude $argv
end

Then, simply type fcc-claude in your terminal to launch it with the proxy routing enabled, or use claude to bypass the proxy.

Security Note — Gateway Auth Token

Currently, your Gateway Token state is: DISABLED.
You can configure a custom token inside the API Credentials pane. If configured, you must set your ANTHROPIC_AUTH_TOKEN override to match that exact token. If left blank, any dummy string is accepted.
